# Marketplace AI Bot

Telegram-бот на базе локальной LLM для консультирования продавцов на маркетплейсах.

## Возможности

Проект находится в разработке.

Планируемые возможности:

* консультации по продажам на маркетплейсах;
* поддержка пользователей;
* работа с контекстом диалога;
* RAG по базе знаний;
* анализ изображений и скриншотов;
* tools / function calling;
* MCP;
* маршрутизация запросов между специализированными агентами;
* логирование и трассировка;
* измерение времени обработки и количества токенов;
* автоматические тесты.

## Tech Stack

* Python
* aiogram
* Ollama
* локальная LLM
* ChromaDB
* RAG
* MCP
* pytest
