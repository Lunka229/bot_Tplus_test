# Marketplace AI Bot

Telegram-бот на базе локальной LLM для консультирования продавцов на маркетплейсах.

Бот работает локально и использует LLM через Ollama. Архитектура проекта включает маршрутизацию запросов, RAG по базе знаний, анализ изображений, function calling и MCP-инструменты.

## Возможности

* консультации продавцов по работе с маркетплейсами;
* специализированные сценарии:

  * экономика товара;
  * маркетинг и реклама;
  * карточка товара;
  * общая поддержка;
* работа с контекстом диалога;
* очистка контекста текущего диалога;
* маршрутизация запросов между специализированными сценариями;
* RAG по локальной базе знаний;
* анализ изображений и скриншотов;
* локальная LLM через Ollama;
* tools / function calling;
* MCP Server и MCP Client;
* MCP-инструмент для расчёта экономики товара;
* проверка аргументов инструментов перед выполнением;
* защита от использования выдуманных пользователем числовых данных;
* prompt engineering:

  * zero-shot prompting;
  * few-shot prompting;
  * role prompting;
  * structured reasoning;
  * инструкции по скрытию внутреннего хода рассуждений;
* логирование и трассировка запросов;
* генерация Request ID для отслеживания запросов;
* измерение времени обработки LLM-запросов;
* подсчёт prompt, completion и total tokens;
* обработка ошибок подключения к LLM;
* автоматические тесты.

## Архитектура

Основной сценарий обработки запроса:

```text
Telegram
   ↓
Bot Handler
   ↓
Request Router
   ↓
RAG Service
   ↓
LLM Service
   ↓
Ollama / локальная LLM
   ↓
Function Calling
   ↓
MCP Client
   ↓
MCP Server
   ↓
Tool
   ↓
Результат инструмента
   ↓
LLM
   ↓
Telegram
```

## MCP

В проекте реализована интеграция с Model Context Protocol.

Доступный MCP-инструмент:

```text
calculate_margin_tool
```

Инструмент рассчитывает:

* прибыль;
* маржинальность;
* наценку.

Пример:

```text
Цена продажи: 2500 ₽
Себестоимость: 1500 ₽

Прибыль: 1000 ₽
Маржинальность: 40%
Наценка: 66.67%
```
